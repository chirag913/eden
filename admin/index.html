How this dashboard works

  1. This dashboard lives at yoursite.com/admin — a separate page from your shop, in its own admin folder. It is not connected to a live database, so there's no server to save changes to automatically.
  2. Edit prices, descriptions, or tags directly in the list below (they save automatically as you type). Add new soaps using the form above.
  3. When you're happy with your changes, click "Download products.json" at the top. This downloads one small file.
  4. Upload that downloaded file to your website's hosting, in the same folder as index.html, replacing the old products.json.
  5. If you added a new soap with a photo, also upload that photo file into your site's images folder — use the exact file name shown when you added it.
  6. Refresh your live website — the changes will now show for everyone.
